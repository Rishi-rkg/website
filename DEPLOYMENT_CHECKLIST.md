# 🚀 DEPLOYMENT CHECKLIST

Use this checklist to ensure your site is properly configured and deployed.

## Before Deployment

- [ ] **Review PREVIEW.html** - Open this file in your browser to see how your site will look
- [ ] **Read QUICK_START.md** - Follow the simple 4-step deployment guide
- [ ] **Check your information** - Make sure cv.md has your correct details

## GitHub Setup

- [ ] Create repository: `your-username.github.io` (use YOUR actual GitHub username)
- [ ] Repository is **Public** (required for free GitHub Pages)
- [ ] Upload ALL files and folders from rishi-portfolio directory
- [ ] Enable GitHub Pages in Settings → Pages
- [ ] Branch: main, Folder: / (root)

## Configuration Updates

- [ ] **_config.yml**
  - [ ] title: "Your Name"
  - [ ] email: your-email@example.com
  - [ ] baseurl: "" (leave empty for username.github.io)
  
- [ ] **_includes/footer.html**
  - [ ] Add your GitHub URL
  - [ ] Add your LinkedIn URL
  
- [ ] **cv.md**
  - [ ] Verify all information is current
  - [ ] Check links are working

## After Deployment

- [ ] Wait 2-3 minutes for GitHub to build site
- [ ] Visit: https://your-username.github.io
- [ ] Test all navigation links
- [ ] Check CV page loads correctly
- [ ] Verify blog page displays example post
- [ ] Test on mobile device

## Create Your First Post

- [ ] Go to repository → _posts folder
- [ ] Click "Add file" → "Create new file"
- [ ] Name: 2024-12-05-my-first-post.md (use today's date)
- [ ] Add frontmatter and content (see QUICK_START.md for template)
- [ ] Commit the file
- [ ] Wait 1-2 minutes and refresh your site

## Optional Enhancements

- [ ] Add your photo to assets/images/
- [ ] Update homepage with personal photo
- [ ] Write 2-3 blog posts about your work
- [ ] Set up custom domain (see README.md)
- [ ] Add Google Analytics (optional)

## Troubleshooting

If something doesn't work:

1. Check repository Actions tab for build errors
2. Verify _config.yml baseurl is correct
3. Make sure repository is Public
4. Wait full 2-3 minutes after pushing changes
5. Clear browser cache and refresh
