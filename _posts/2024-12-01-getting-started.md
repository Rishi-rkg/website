## How to Write a New Blog Post

Creating a new blog post is simple:

1. Create a new file in the `_posts` folder
2. Name it following this format: `YYYY-MM-DD-title-of-post.md`
3. Add the frontmatter at the top (see below)
4. Write your content in Markdown
5. Push to GitHub

## Frontmatter Template

Every post needs frontmatter at the top:

```yaml
---
layout: post
title: "Your Post Title Here"
date: 2024-12-01
---
```

## Markdown Formatting

You can use all standard Markdown formatting:

### Headers

Use `##` for main sections, `###` for subsections.

### Lists

- Item one
- Item two
- Item three

### Code

Inline `code` looks like this, and code blocks look like this:

```python
def hello_world():
    print("Hello, world!")
```

### Images

To add images to your blog posts:

1. Place images in the `assets/images` folder
2. Reference them like this:

```markdown
![Alt text](/assets/images/your-image.jpg)
```

### Links

Add links like this: [Link text](https://example.com)
